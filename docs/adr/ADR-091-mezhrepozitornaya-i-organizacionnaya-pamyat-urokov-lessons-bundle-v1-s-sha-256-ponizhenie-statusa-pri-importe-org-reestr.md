# ADR-091. Межрепозиторная и организационная память уроков: lessons-bundle/v1 с SHA-256, понижение статуса при импорте, org-реестр

- Date: 2026-10-14
- Status: Accepted
- Модель-автор: spine-arch (оркестратор), по TASK-Spine-0.5.0-learning-loop.md
- Дельта: `changes/learning-loop-050/DELTA.md` (пункт L10)

## Context

Уроки уровня `repo` заперты в репозитории; перенос между репозиториями и накопление на уровне организации (критерий «урок переживает смену команды/проекта») невозможны. Но чужой урок — это чужое доказательство: переносить его с сохранением статуса `confirmed` значит доверять чужому гейту без проверки (риск 6 TASK — утечка между репозиториями; риск отравления чужим evidence).

## Decision

1. `arch-be lessons export --scope repo --min-status confirmed` → **lessons-bundle/v1**: JSON с evidence-хэшами, версией arch-be и подписью SHA-256 (как receipt у archify).
2. `import` в уровень `user` или `org` — **с понижением статуса до `candidate`**: чужой урок обязан подтвердиться своим гейтом. Урок с несовпавшим хэшем отклоняется (тест).
3. Org-реестр — git-репозиторий или каталог, путь в `[lessons] org_dir`; доступен через MCP для хост-агентов (Core).
4. Уроки уровней `user`/`org` не пишутся в файлы репозитория без флага `--share` (анти-утечка).

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| **A. Подписанный бандл + понижение статуса (выбран)** | Доверие проверяется своим гейтом; подпись = целостность и атрибуция | Импортированный урок требует повторного подтверждения — медленнее распространение |
| B. Импорт с сохранением статуса | Мгновенный перенос | Чужой гейт ≠ наш гейт; отравление org-реестра одним скомпрометированным репо |
| C. Только ручное копирование LESSONS.md | Ноль кода | Нет evidence, нет счётчиков, нет статусов — это текст, а не память |
| D. Статус-кво | Ноль кода | Знание заперто в репозитории; E2 между командами недостижим |

## Consequences

### Positive

- Память масштабируется до организации без потери дисциплины доказательств.
- Подпись и понижение статуса делают отравление org-реестра дорогим и видимым.

### Negative

- Org-реестр — новый общий ресурс (права, политика чистки, владелец).
- Понижение статуса замедляет распространение хороших уроков (осознанная цена: доверие зарабатывается заново).
- Формат lessons-bundle/v1 — новый стабильный контракт, изменения — только аддитивно.

## Reversibility

reversible. Экспорт/импорт аддитивны; org-реестр опционален (`org_dir` пуст — механика выключена). Откат — revert коммита L10.
