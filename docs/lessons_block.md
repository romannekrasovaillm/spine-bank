# Блок уроков в контексте (инъекция реестра)

Закреплённый блок `## Уроки контура (выучено, проверено гейтом)` — канал, которым
выученное (реестр уроков, `docs/failure_memory.md`, ADR-085) доезжает до модели и
до исполнителя. Решение: **ADR-087**; реализация: `src/lesson_block.rs`.

## Зачем

Живые прогоны 0.4.10 показали три дыры (B2, B5, B8):

- урок, записанный в `failure_lessons.md`, не читал никто (B2);
- правило, попавшее в диалог свободным текстом, маскировалось L1-прунингом и
  пересказывалось L3-саммари вместе с шумом (B5);
- субагенты и ralph-раунды стартуют со свежим контекстом, и опыт родителя до
  них не доходил (B8).

Блок закрывает все три: он **пересобирается из реестра** при каждом обращении,
поэтому его нельзя ни потерять, ни «пересказать».

## Точки инъекции

| Точка | Что получает | Где в коде |
|---|---|---|
| Сессия (TUI, `arch-be run`) | блок в системном промпте каждого запроса | `agent.rs` (`build_request` → `effective_system_prompt`) |
| Ход агента | пересборка блока по путям и тексту ввода | `agent.rs` (`retarget_lessons_block`) |
| Компактификация (L1, прунинг, L3) | пересборка блока из реестра после каждой ступени | `agent.rs` (`refresh_lessons_block`) |
| Задача исполнителю | блок перед текстом задачи (`harness_run`, `arch-be harness-run`) | `harness.rs`, `cli/mod.rs` |
| Субагент, ralph-раунд | блок в системном промпте свежей сессии | `subagent.rs`, `ralph.rs` (через `AgentSession`) |
| Claude Code / Kimi Code | блок в stdout хуков `SessionStart`/`UserPromptSubmit` | `hook.rs`, `connect/hooks.rs` |

Отбор (детерминированный, без LLM — AD-2):

1. пригодность: не `retired` и `misses = 0` (урок, который начал мешать,
   выводится из блока автоматически);
2. область: глоб области урока против путей задачи (`scope`), пустой список
   путей — вся область репозитория (старт сессии);
3. релевантность: BM25 (`src/kb.rs`) текста задачи против формулировок урока;
4. порядок: статус (`promoted` > `confirmed` > `candidate` > `observed`),
   затем вес BM25, затем `hits`, затем `id`;
5. потолки: `[lessons] k` (сколько уроков) и `[lessons] token_limit`
   (оценка — символы / 4). Лимит жёсткий: блок либо влезает целиком, либо
   не инжектируется.

### Префлайт-подбор под задачу (L4)

Для **задачи исполнителю** (точка `harness_run`) отбор идёт не общим `rank`, а
префлайтом [`lessons_match`](`src/lessons/match.rs`): BM25 текста задачи против
`statement` **и** `signature` (код/вид субъекта), приоритет статусов
`confirmed` > `candidate` > `observed`; отобранные уроки кладутся в
`Report.lessons` и при зелёном вердикте приёмки пишут событие журнала
`prevented` (L4, читается `metrics --learning`). Сессия и хуки остаются на
общем `rank` (L3).

## Реестры

Блок собирается из двух журналов: `<repo>/.arch/lessons/ledger.jsonl`
(уровень репозитория) и `$ARCH_HOME/lessons/ledger.jsonl` (уровень
пользователя; переопределяется `[lessons] user_dir`). При совпадении `id`
побеждает репозиторный урок. Отсутствие реестра — пустой блок, не ошибка.

## Гигиена: уроки — данные, а не инструкции

Текст урока может родиться из stdout исполнителя, то есть недоверенный
(риск 1 TASK, TB-2 модели угроз). Поэтому:

- блок обёрнут маркером данных `<!-- DATA lessons begin … -->` … `<!-- DATA lessons end -->`;
- перед попаданием в блок формулировка проходит сканер `src/injection.rs`;
  срабатывание = **карантин**: урок в контекст не идёт, а факт отсечения
  остаётся append-only строкой в `.arch/lessons/quarantine.jsonl`
  (AD-5: журнал — источник аудита) и строкой в stderr хука;
- статус урока карантин не меняет: жизненный цикл решают счётчики
  доказательств (AD-2).

## Флаг и обратимость

Всё поведение — за `[lessons] enabled` (по умолчанию `false` до волны 3):
выключенный флаг даёт пустой блок на всех путях, реестр не читается,
`connect` не ставит хуки уроков. Откат — revert коммита L3.

## Проверка

- `cargo test` — юнит-тесты `lesson_block` (отбор, лимит токенов, карантин),
  `hook` (fail-soft хуков), `agent::tests` (блок после L1/L3-компактификации,
  синтетический B5: 50 ходов шума), `subagent` (свежий контекст);
- `cargo test --test lessons_injection` — CLI-контракт: пустой вывод хука без
  реестра (exit 0), блок в stdout с реестром, отбор по путям промпта,
  миграция `failure_lessons.md`, блок в задаче `harness-run` и его отсутствие
  при `enabled = false`.
