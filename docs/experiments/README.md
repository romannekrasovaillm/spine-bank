# Эксперименты — живые прогоны архитектора в чужом харнессе

Здесь лежат отчёты живых экспериментов по методологии **«Spine Core без
своей LLM»**: роль модели (проектирование, суждение, формулировки) берёт на
себя внешний кодовый агент (Claude Code), а Spine исполняет только
детерминированный контур — гейты, модель, трассировку, NFR, evidence — без
единого API-ключа. Эксперименты проверяют, что ценность контура не зависит
от наличия у Spine собственной модели, и честно фиксируют как измеренные
ценности, так и границы (что остаётся методикам-скиллам и человеку).
