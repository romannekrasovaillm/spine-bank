# Мутационное тестирование ядра (волна C2, 0.3.7) — 2026-09-24

Проверка того, что тесты детерминированного контура (гейт, дифф контрактов,
пакеты доказательств) реально ловят сломанный код, а не только «зеленеют» —
cargo-mutants гоняет точечные мутации исходника через весь `cargo test`.

## Установка и скоуп

- Инструмент: `cargo-mutants 27.1.0` (уже установлен, `~/.cargo/bin`).
- Конфиг: `.cargo/mutants.toml` — скоуп `src/gate/**`, `src/contract_diff/**`,
  `src/evidence.rs`; testkit/mod.rs исключены (фикстуры и реэкспорты);
  таймауты: `timeout_multiplier = 3.0`, `minimum_test_timeout = 120`.
- Всего в скоупе: **823 мутанта** (`cargo mutants --list`), по файлам —
  от 162 (`src/evidence.rs`) до 4 (`src/contract_diff/tools.rs`).

Нюансы версии 27.1.0, важные для воспроизведения:

- Конфиг читается **только** из `.cargo/mutants.toml` (корневой
  `mutants.toml` молча игнорируется). В репозитории `.cargo/` в `.gitignore`
  как служебный каталог — добавлено исключение `!.cargo/mutants.toml`.
- CLI `--file <glob>` НЕ перекрывает `examine_globs` из конфига — множества
  объединяются. Для точечного локального прогона конфиг временно
  откладывался в сторону, таймауты передавались флагами.
- Каталог результатов `mutants.out/` (копии дерева, логи) в `.gitignore`;
  в коммит идёт только этот отчёт.

## Локальный прогон-доказательство

Файл `src/contract_diff/report.rs` (10 мутантов — самый маленький
содержательный файл скоупа; бокс 18 минут, `-j 3`):

```text
ok       Unmutated baseline in 74s build + 31s test
10 mutants tested in 6m: 1 missed, 9 caught
```

Стоимость мутанта после прогретого бейзлайна: ~30–40 с инкрементальной
сборки + ~40 с тестов.

### Выживший мутант → тест

`report.rs:17` — `replace - with + in render_report`:
`non_breaking = findings.len() - breaking` → мутант `+` выживал: существующие
тесты (через `tools.rs`) проверяли JSON-форму отчёта, а текстовую шапку
`render_report` — нет.

Тест добавлен: `render_report_counts_breaking_and_non_breaking`
(`src/contract_diff/report.rs`, модуль `tests`) фиксирует счётчики
`breaking/non-breaking` в текстовой шапке и строку `Итог: PASS/FAIL` для
обоих случаев. Перепроверка мутанта после добавления теста:

```text
1 mutant tested in 2m: 1 caught
```

Итог по файлу после доработки: **10/10 caught, выживших нет.**

## Что отложено в nightly

Полный скоуп (823 мутанта) локально не гонялся: ~80 с на мутанта даже на
12 потоках — это часы; место ему в ночной джобе `mutants`
(`.github/workflows/nightly.yml`): матрица из 12 шардов
(`--shard N/12`, ≈69 мутантов на шард, прогноз 2,5–3,5 ч на шард при лимите
джобы 6 ч), артефакт `mutants.out` на шард (`if: always()` — частичные
результаты сохраняются и при таймауте). Красная джоба = выжившие мутанты:
по артефакту добавляются тесты (как выше) или обоснование.
