## Структурная причина 100 % пустых (честно)

spine-bank — одно-крейтовый репозиторий: один `Cargo.toml` в корне, вся
разработка ядра (включая merge wave-K с +5095 строками `src/arch_diff/`)
по гранулярности K1 — внутри одного компонента. Кейсы `кейсы/*` не создают
узлов: у них нет манифестов сборки (кроме `drift-control`), а их модели
читаются только из КОРНЯ снимка (`model/`), не из `кейсы/*/model/`. Поэтому
«100 % пустых» — не «инструмент сломан» (контрольные зонды непустые) и не
«в истории не было архитектуры» (контракт ТСП — был и показан), а
несовпадение гранулярности инструмента с формой этого репозитория.

## Вывод и рекомендация

Цифры за тишину: 0 ложных срабатываний и 0 ложных переименований на 38
реальных диффах, детерминизм, время приемлемое (кейс — секунды, крупный
моно-репозиторий — десятки секунд). Экран «один PR — один дифф» на
многокомпонентном кейсе работает как задумано.

Но на одно-крейтовом репозитории без корневой `model/` дифф структурно пуст:
фича там не врёт, а молчит — ценности «архитектор ревьюит архитектуру» для
таких репозиториев она сейчас не даёт.

**Рекомендация (пороги — [РЕШЕНИЕ ЧЕЛОВЕКА]):** объявлять фичу применимой
(не «стабильной для всех») с явной границей в документации: репозитории с
моделью и `code_roots` либо с несколькими манифестами/workspaces —
измеримо точны; одно-крейтовые без модели — дифф будет пустым по
построению. Кандидат на доработку (вне K8): inferred-узлы уровня
«каталог верхнего уровня src/» для одно-крейтовых репозиториев — тогда
merge вроде wave-K дал бы ребро/узел, а не пустоту.

## Честные границы замера

- Выборка наследует уклон D4: история одного репозитория, одно-крейтового;
  точность на multi-component репозиториях измерена зондом, не выборкой.
- 15 из 38 времён переписывания сводки потеряны сбоем скрипта (Unicode в
  субъектах коммитов под `LC_ALL=C`); сами JSON-артефакты целы, выводы по
  ним полные. Время по 23 замерам + отдельные серии по 3 прогона.
- Debug-бинарь; release быстрее (оценка не замерялась — порог производительности
  для CI-джобы K4 отдельным решением).
