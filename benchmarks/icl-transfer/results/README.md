# results/ — сводки прогонов icl-transfer

Генерируется `run_all.sh`; детерминированный прогон `--ci` пишет в
`ci-<date>/`:

- `ci-summary.json` — машиночитаемая сводка (руки, метрики, анти-Goodhart);
- `ci-report.md` — таблица «значение → порог» (пороги — `PREREGISTRATION.md` §4);
- `run.log` — полный вывод прогона (пути санитизированы под AD-7).

Живой прогон `--live` (волна 3) заполнит таблицу «до → после» раздела 9 TASK.
Сами сводки прогонов не коммитятся (детерминированно воспроизводятся одной
командой); в VCS — только этот README.
