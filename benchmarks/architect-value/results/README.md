# results/ — журнал прогонов (коммитится)

Каталоги прогонов: `results/<версия>-<дата>/` со `summary.md` (сводка по сьютам
и метрикам) и `run_all.log` (полный вывод). Прогон запускается `run_all.sh`;
переменная `ARCH_VALUE_OUT` меняет корень вывода, по умолчанию — сюда.

## Провенанс «до» (baseline 0.3.16)

Числа «до» в `PREREGISTRATION.md` §2 — из живого прогона 2026-10-10 на 0.3.16
(commit `8e5f9d6`), зафиксированного в `TASK-Spine-0.4.0-architect-value.md` §2.
Повторный прогон `run_all.sh` на 0.3.17 воспроизводит ту часть, что живёт на
этой версии (survey-детерминизм, control check семян/стандарта, MCP-проба,
arch-diff-replay), и печатает SKIP для механик волн R/S/K/D. SKIP ≠ PASS.
