# Эксперимент: OpenSpec-стиль против спайн-формата (масштабный прогон)

Дата прогона: 2026-09-05. Верификация: 2026-09-06.
Развитие мини-пилота (см. `pilot_PROOF.md`, 3×3×1, A=23/B=5/C=2).

**Дизайн.** 10 задач (Rust, платёжный домен, один самодостаточный файл на
генерацию) × 3 контекста × 3 прогона × 2 модели (deepseek-v4-flash,
glm-5.3-flash) = **180 генераций**. Температура 0.7, max_tokens 6000.
Пререгистрация хэшей правил/постановок/гейта до генераций
(`PREREGISTRATION.md`, `logs/context_hashes.txt`). Контексты обеих серий
писала «вторая рука» — независимая модель-генератор glm-5.3 (полная),
нейтральным промптом из `ORG-STANDARDS.md` + постановок; CLI OpenSpec и
Spine-BE контексты не создавали. Судья — один детерминированный гейт
`arch-be control check --constraints CONSTRAINTS.massrun.yaml` для всех
180 ячеек (без LLM).

**Результат.** A (без контекста) = 367 / B (OpenSpec-стиль) = 32 /
C (спайн) = 24 error-нарушений; чистые генерации 0 % / 73 % / 83 %.
Ложные срабатывания regex-гейта: B −6, C −3 → скорректированные суммы
26 / 21 (−19 % против сырых −25 %). Преимущество спайна модель-зависимое
(deepseek-v4-flash 17/18 — паритет; glm-5.3-flash 15/6 — весь выигрыш);
bootstrap-интервалы средних перекрываются. Остаточный устойчивый класс —
`lock().unwrap()` (B=21, C=18): пробивает оба формата контекста.
Полный разбор — `RESULTS.md`, машиночитаемо — `results.jsonl` (180 записей)
и `summary.json`.

## Состав каталога

- `RESULTS.md` — методология, таблицы, разрезы, ограничения, выводы.
- `results.jsonl` — 180 записей (метаданные генерации + нарушения по правилам).
- `summary.json` — агрегаты.
- `PREREGISTRATION.md`, `TASKS.md`, `ORG-STANDARDS.md`,
  `CONSTRAINTS.massrun.yaml`, `CONTEXT_EDITS.md` — замороженные входы.
- `contexts/` — 20 контекстов (10 задач × B/C) + журнал генерации контекстов.
- `logs/context_hashes.txt` — sha256 контекстов до прогонов.
- `pilot_PROOF.md` — протокол мини-пилота (3×3×1).
- Скрипты воспроизведения: `generate_contexts.py`, `massrun_generate.py`,
  `gate_all.py`, `analyze.py` (требуют ключи API и бинарь arch-be).

**Не включено:** `cells/` (180 каталогов с prompt/raw/src/meta каждой
генерации, ~рабочая зона прогона) — остались в `/tmp/openspec_spine_massrun/`
на машине эксперимента; при необходимости переносятся отдельно.
