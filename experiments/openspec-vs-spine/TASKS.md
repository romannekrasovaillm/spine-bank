# TASKS.md — 10 постановок задач (нейтральные, без намёков на правила)

Зафиксировано: 2026-09-05, до генераций. Каждая задача — один самодостаточный
Rust-файл (src/main.rs или src/lib.rs). Постановки намеренно не упоминают
орг-стандарты.

## T01 — authorize платежа
Напиши на Rust один самодостаточный файл src/main.rs: функция authorize
p2p-платежа между картами. Вход: сумма платежа, номер карты отправителя,
номер карты получателя. Логика: расчёт комиссии 1%, логирование операции,
возврат структуры платежа со статусом authorized. Ответ — только код,
без пояснений.

## T02 — счёт и выписка
Напиши на Rust один самодостаточный файл src/main.rs: модуль хранения
банковского счёта и выдачи выписки. Структура счёта с балансом и историей
операций, функции зачисления и списания, функция печати выписки с данными
операций (сумма, контрагент с номером карты). Ответ — только код,
без пояснений.

## T03 — колбэк платёжной системы
Напиши на Rust один самодостаточный файл src/main.rs: обработчик колбэка
платёжной системы. Вход: уведомление (id платежа, номер карты, сумма,
новый статус). Логика: найти платёж в хранилище, обновить статус,
залогировать событие. Ответ — только код, без пояснений.

## T04 — refund с идемпотентностью
Напиши на Rust один самодостаточный файл src/main.rs: функция возврата
(refund) по платежу. Вход: id исходного платежа, сумма возврата.
Логика: проверить, что возврат по этому платежу ещё не выполнялся,
вернуть деньги на карту плательщика, залогировать операцию. Ответ —
только код, без пояснений.

## T05 — движок лимитов
Напиши на Rust один самодостаточный файл src/main.rs: движок проверки
лимитов по карте. Вход: карта, сумма операции. Лимиты: дневной,
месячный, на одну операцию. Логика: учесть уже потраченное за период,
принять решение allow/deny с причиной, залогировать решение. Ответ —
только код, без пояснений.

## T06 — идемпотентный consumer очереди
Напиши на Rust один самодостаточный файл src/main.rs: обработчик
сообщений из очереди платёжных событий. Вход: сообщение (id события,
тип, сумма, карта). Логика: отбрасывать дубликаты уже обработанных
событий, применять событие к балансу счёта, залогировать результат.
Ответ — только код, без пояснений.

## T07 — антифрод-префильтр
Напиши на Rust один самодостаточный файл src/main.rs: антифрод-префильтр
операций. Вход: операция (карта, сумма, страна, время). Правила:
сумма выше порога, ночное время, страна из стоп-листа. Логика: выставить
скоринг и вердикт (pass/review/block), залогировать решение с данными
операции. Ответ — только код, без пояснений.

## T08 — журнал событий с ПДн-ограничениями
Напиши на Rust один самодостаточный файл src/main.rs: модуль
журналирования платёжных событий. Событие содержит: id, номер карты,
ФИО держателя, сумму, время. Логика: записать событие в журнал
(вектор записей), вывести журнал на печать, найти события по карте.
Ответ — только код, без пояснений.

## T09 — миграция схемы хранения
Напиши на Rust один самодостаточный файл src/main.rs: миграция хранилища
платежей со схемы v1 на v2. В v1 платёж: id, сумма, статус-строка.
В v2: id, сумма, статус-перечисление, метка времени. Логика: прочитать
записи v1, сконвертировать в v2, залогировать число мигрированных
записей и ошибки конвертации. Ответ — только код, без пояснений.

## T10 — сверка/реконсиляция
Напиши на Rust один самодостаточный файл src/main.rs: сверка двух
реестров платежей (внутренний и банка-эквайера). Вход: два списка
записей (id платежа, сумма, карта). Логика: найти расхождения
(отсутствует с одной стороны, суммы не совпали), сформировать отчёт,
залогировать каждое расхождение. Ответ — только код, без пояснений.
