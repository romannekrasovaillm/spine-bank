1. ЗАПРЕЩЕНО использовать `f64`/`f32` для денег, комиссий, лимитов и остатков. Проверка: grep по `f64`, `f32` в продуктовом коде платёжного домена; суммы должны быть только `i64` (minor units) или `Decimal`.

2. ЗАПРЕЩЕНО выполнять mutating-операции (списание, зачисление, возврат, обновление статуса, запись в журнал) без обязательного ключа идемпотентности. Проверка: каждая такая функция принимает `idempotency_key`; повторный вызов с тем же ключом возвращает сохранённый результат без повторного изменения состояния.

3. ЗАПРЕЩЕНО вызывать `.unwrap()`, `.expect(...)`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` в прод-коде. Проверка: grep по этим конструкциям; обработка ошибок — только через `Result` с `?` или явной обработкой.

4. ЗАПРЕЩЕНО логировать PAN, ФИО держателя, паспортные данные, телефоны, адреса. Проверка: ревью логов и журналов; допустима только маска карты (BIN + последние 4 цифры, остальное — `*`).

5. ЗАПРЕЩЕНО возвращать ошибки строками (`Err("...")`, `String`, `Box<dyn Error>`) в продуктовом коде. Проверка: ошибки — типизированные enum (thiserror-стиль) с вариантом на каждый класс сбоя и реализацией `Display` + `Error`.

6. ЗАПРЕЩЕНО использовать `static mut`, `lazy_static!`, `static ref` и глобальные `static Mutex/RwLock` с состоянием домена. Проверка: grep по указанным конструкциям; состояние передаётся явно через владение, параметры или конструктор.

7. ЗАПРЕЩЕНО выполнять сетевые вызовы (HTTP, TCP, очередь) без явно заданного таймаута. Проверка: ревью каждого сетевого вызова — таймаут задан явно; блокирующие вызовы без таймаута не проходят ревью.

8. ЗАПРЕЩЕНО хранить ключи, пароли, токены литералами в коде. Проверка: секреты читаются только через `std::env::var`; grep по подозрительным литералам.

9. ЗАПРЕЩЕНО пропускать журналирование денежных событий без ключа идемпотентности, суммы в minor units, валюты и результата. Проверка: каждое денежное событие журналируется с указанными полями; журнал не содержит ПДн/PAN.

10. ЗАПРЕЩЕНО публичным функциям домена возвращать что-либо, кроме `Result<T, DomainError>`. Проверка: сигнатуры публичных функций; набор вариантов ошибки — часть контракта функции.
