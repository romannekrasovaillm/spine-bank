1. ЗАПРЕЩЕНО использовать `f64`/`f32` для денег, комиссий, лимитов и остатков. Проверка: греппоиск `f32`/`f64` в сигнатурах и структурах домена; суммы — только `i64` (minor units) или `Decimal`.

2. ЗАПРЕЩЕНО выполнять mutating-операции (списание, зачисление, возврат, обновление статуса, запись в журнал) без ключа идемпотентности. Проверка: каждая mutating-функция принимает `idempotency_key`; повторный вызов с тем же ключом возвращает сохранённый результат без изменения состояния.

3. ЗАПРЕЩЕНО вызывать `.unwrap()`, `.expect(...)`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` в прод-коде. Проверка: греппоиск по этим паттернам; ошибки — только через `Result` с `?` или явной обработкой.

4. ЗАПРЕЩЕНО писать в логи PAN, ФИО держателя, паспортные данные, телефоны, адреса. Проверка: инспекция строк логирования; допустима только маска карты (BIN + последние 4 цифры, остальное — `*`).

5. ЗАПРЕЩЕНО возвращать ошибки строками (`Err("...")`, `String`, `Box<dyn Error>`) в продуктовом коде. Проверка: ошибки — типизированные enum в стиле thiserror с вариантом на класс сбоя и реализацией `Display` + `Error`.

6. ЗАПРЕЩЕНО заводить глобальное мутабельное состояние (`static mut`, `lazy_static!`, `static ref`, глобальные `static Mutex/RwLock` с доменным состоянием). Проверка: греппоиск указанных паттернов; состояние передаётся явно через владение, параметры, конструктор.

7. ЗАПРЕЩЕНО выполнять сетевые вызовы (HTTP, TCP, очередь) без явно заданного таймаута. Проверка: каждый сетевой вызов конфигурируется таймаутом; блокирующие вызовы без таймаута не проходят ревью.

8. ЗАПРЕЩЕНО хранить секреты (ключи, пароли, токены) литералами в коде. Проверка: секреты читаются только через `std::env::var`; греппоиск литералов ключей/паролей/токенов.

9. ЗАПРЕЩЕНО проводить денежное событие без журналирования. Проверка: для каждого события в журнале есть ключ идемпотентности, сумма в minor units, валюта, результат; журнал не содержит ПДн/PAN (см. инвариант 4).

10. ЗАПРЕЩЕНО публичным функциям домена возвращать что-либо, кроме `Result<T, DomainError>`. Проверка: сигнатуры всех публичных функций; набор вариантов `DomainError` — часть контракта функции.
