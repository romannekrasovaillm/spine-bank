1. ЗАПРЕЩЕНО использовать f64/f32 для денег, комиссий, лимитов и остатков. Проверка: денежные суммы — только i64 minor units или Decimal; grep по f32/f64 в расчётах домена.

2. ЗАПРЕЩЕНО mutating-операции (списание, зачисление, возврат, смена статуса, запись в журнал) без ключа идемпотентности. Проверка: каждая операция принимает idempotency_key; повторный вызов с тем же ключом возвращает сохранённый результат без изменения состояния.

3. ЗАПРЕЩЕНО использовать unwrap/expect/panic/unreachable/todo/unimplemented в продуктовом коде. Проверка: ошибки обрабатываются через Result с явным пробросом `?` или обработкой.

4. ЗАПРЕЩЕНО логировать PAN, ФИО держателя, паспортные данные, телефоны и адреса. Проверка: в логах и журналах допускается только маска карты (BIN + последние 4 цифры, остальное `*`).

5. ЗАПРЕЩЕНО возвращать ошибки строками (Err("..."), String, Box<dyn Error>). Проверка: ошибки — типизированные enum (thiserror-стиль, вариант на класс сбоя, реализация Display + Error); публичные функции домена возвращают Result<T, DomainError> с фиксированным набором вариантов как частью контракта.

6. ЗАПРЕЩЕНО глобальное мутабельное состояние (static mut, lazy_static!, static ref, static Mutex/RwLock с доменным состоянием). Проверка: состояние передаётся явно через владение, параметры, конструктор.

7. ЗАПРЕЩЕНО выполнять сетевые вызовы без явно заданного таймаута и хранить секреты литералами в коде. Проверка: HTTP/TCP/очереди всегда с таймаутом; ключи, пароли, токены читаются только из std::env::var; каждое денежное событие журналируется (ключ идемпотентности, сумма в minor units, валюта, результат) без ПДн/PAN.
