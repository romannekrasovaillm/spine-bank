1. ЗАПРЕЩЕНО использовать `f64`/`f32` для денег, комиссий, лимитов и остатков. Проверка: суммы хранятся и вычисляются только в minor units (`i64`) или через Decimal; grep по типам `f64`/`f32` в продуктовом коде платёжного домена не должен находить применений к денежным величинам.

2. ЗАПРЕЩЕНО выполнять mutating-операцию (списание, зачисление, возврат, обновление статуса, запись в журнал) без ключа идемпотентности. Проверка: каждая такая операция принимает обязательный `idempotency_key`; повторный вызов с тем же ключом возвращает сохранённый результат без повторного изменения состояния.

3. ЗАПРЕЩЕНО использовать `.unwrap()`, `.expect(...)`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` в прод-коде. Проверка: статический поиск этих конструкций в продуктовом коде даёт пустой результат; обработка ошибок — только через `Result` с `?` или явной обработкой.

4. ЗАПРЕЩЕНО попадание в логи и журналы полного PAN, ФИО держателя, паспортных данных, телефонов и адресов. Проверка: просмотр журнала содержит только маску карты (BIN + последние 4 цифры, остальное — `*`).

5. ЗАПРЕЩЕНО возвращать ошибки строками (`Err("...")`, `String`, `Box<dyn Error>`) в продуктовом коде. Проверка: ошибки — типизированные enum (по одному варианту на класс сбоя, реализация `Display` + `Error`).

6. ЗАПРЕЩЕНО использовать `static mut`, `lazy_static!`, `static ref` и глобальные `static Mutex/RwLock` с состоянием домена. Проверка: состояние передаётся явно (владение, параметры, конструктор).

7. ЗАПРЕЩЕНО выполнять сетевые вызовы (HTTP, TCP, очередь) без явно заданного таймаута. Проверка: любой сетевой вызов сопровождается таймаутом; блокирующие вызовы без таймаута отсутствуют.

8. ЗАПРЕЩЕНО хранить секреты (ключи, пароли, токены) литералами в коде. Проверка: секреты читаются только из переменных окружения (`std::env::var`).

9. ЗАПРЕЩЕНО денежное событие без журналирования. Проверка: каждое денежное событие записано в журнал с ключом идемпотентности, суммой в minor units, валютой и результатом; журнал соответствует запрету на ПДн/PAN.

10. ЗАПРЕЩЕНО публичной функции домена возвращать что-либо, кроме `Result<T, DomainError>`. Проверка: сигнатуры публичных функций возвращают `Result<T, DomainError>`; набор вариантов ошибки — часть контракта функции.
