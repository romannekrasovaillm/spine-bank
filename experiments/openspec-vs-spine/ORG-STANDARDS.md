# ORG-STANDARDS.md — Организационные стандарты разработки платёжного ядра

Версия 1.0. Зафиксирован: 2026-09-05, до начала эксперимента.
Документ применяется ко всему продуктовому коду платёжного домена (Rust).

## S-01. Деньги — не числа с плавающей точкой
Денежные суммы хранятся и вычисляются только в minor units (целые копейки,
`i64`) либо через десятичный тип Decimal. Использование `f64`/`f32` для
денег, комиссий, лимитов и остатков запрещено.

## S-02. Ключ идемпотентности на mutating-операциях
Каждая операция, изменяющая состояние (списание, зачисление, возврат,
обновление статуса, запись в журнал), принимает обязательный ключ
идемпотентности (`idempotency_key`). Повторный вызов с тем же ключом
возвращает сохранённый результат без повторного изменения состояния.

## S-03. Запрет unwrap/expect/panic в прод-коде
В продуктовом коде запрещены `.unwrap()`, `.expect(...)`, `panic!`
(и аналоги: `unreachable!`, `todo!`, `unimplemented!`). Обработка ошибок —
только через `Result` с явным пробросом (`?`) или обработкой.

## S-04. Запрет персональных данных и PAN в логах
В логи и журналы не попадают: полный номер карты (PAN), ФИО держателя,
паспортные данные, телефоны, адреса. Допустима только маска карты
(BIN + последние 4 цифры, остальное — `*`).

## S-05. Типизированные ошибки
Ошибки представлены типизированными перечислениями (enum ошибок в стиле
thiserror: вариант на каждый класс сбоя, реализация `Display` + `Error`).
Возврат ошибок строками (`Err("...")`, `String`, `Box<dyn Error>`)
в продуктовом коде запрещён.

## S-06. Запрет глобального мутабельного состояния
Запрещены `static mut`, `lazy_static!`, `static ref` и глобальные
`static Mutex/RwLock` с состоянием домена. Состояние передаётся явно
(владение, параметры, конструктор).

## S-07. Сетевые вызовы — только с таймаутом
Любой сетевой вызов (HTTP, TCP, очередь) выполняется с явно заданным
таймаутом. Блокирующие вызовы без таймаута запрещены.

## S-08. Секреты — только из окружения
Ключи, пароли, токены читаются только из переменных окружения
(`std::env::var`). Секреты литералами в коде запрещены.

## S-09. Журналирование денежных событий
Каждое денежное событие журналируется: ключ идемпотентности, сумма
в minor units, валюта, результат. Журнал подчиняется S-04 (без ПДн/PAN).

## S-10. Контракт ошибок у публичных функций
Публичные функции домена возвращают `Result<T, DomainError>`; набор
вариантов ошибки является частью контракта функции.
