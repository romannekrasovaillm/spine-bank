# Очередь улучшений Spine (живой бэклог из тестов/отчётов)

Пополняется из живых тестов субагентов и внешних отчётов; разбирается
патч-пакетами с приоритетом: false-green > error-quality > UX. Каждый пункт
обязан иметь источник (команда/отчёт) и проверяемый критерий.

## Малые (патч-пакет 0.4.10+, кyxня UX)

- [ ] **`mcp list` офлайн-виснет** (живой тест Harness 0.4.8, замечание 2):
  последовательные живые опросы внешних серверов, дефолт таймаута
  180 с на каждое подключение (src/mcp.rs:433, config.rs:181) — в
  офлайн-периметре банка команда «зависает» суммарно на минуты.
  Фикс-кандидат: (а) `--offline`/`--no-probe` флаг — только конфиг без
  живых опросов; (б) суммарный бюджет всего вызова (напр. 10 с) с частичным
  выводом «сервер N не отвечает (таймаут X с)»; (в) параллельные опросы.
  Критерий: `mcp list` в среде без сети завершается ≤ 10 с с явным
  перечнем недоступных.
- [ ] **`agents-md refresh --repo X`** (живой тест Harness 0.4.8,
  замечание 3): флаг отвергнут, только позиционный — консистентность с
  соседями (harness_run принял `repo` как синоним `path`). Фикс-кандидат:
  принять `--repo` как алиас позиционного (или единый `--path`). Критерий:
  оба синтаксиса работают, тест.
- [ ] **Подсказка unknown-field после 0.4.10** (ADR-081 п.5): при выходе
  FLOW/meta_id/registry_api/agreement в шапке текст «держите в теле
  карточки» меняется на «доступны в шапке с 0.4.10» — не забыть в волне
  flow-v1.
- [ ] **score anti-bypass wording** (живой тест Core 0.4.8): «ВНИМАНИЕ —
  расхождение: заявлено флагами vs видно по диффу: new_component»
  печатается и когда флаги не задавались вовсе (floor-механика детектора)
  — wording вводит в заблуждение. Фикс: различать «флаги заданы и
  противоречат» (расхождение) от «флаги не заданы, детектор поднял floor»
  (информативная строка без слова «расхождение»). Критерий: без флагов —
  строка без «ВНИМАНИЕ — расхождение»; тест.
- [ ] **must_not_contain без glob самосканируется** (живой тест Core
  0.4.8): правило без glob (дефолт `**/*`) находит паттерн в самом
  CONSTRAINTS.yaml («самонаходки», 14 вместо 3). Фикс-кандидат: реестры
  CONSTRAINTS.yaml/CONSTRAINTS.corp.yaml и .arch-handoff/ копии — в
  дефолтном наборе исключений (с явным комментарием в доке, что при
  явном glob файла реестра он сканируется намеренно). Критерий: правило
  без glob не даёт находок в собственном файле реестра; тест.
- [ ] **must_contain: «glob пуст» vs «паттерн не найден»** (живой тест
  Core 0.4.8): warn «паттерн не найден ни в одном файле» не различает
  ноль файлов по glob (набор пуст — возможно неверный glob) и файлы без
  паттерна (правило нарушено). Фикс: два разных сообщения/warn-кода;
  «файлов по glob: 0» — отдельный warn с намёком проверить glob.
  Критерий: тест на оба случая.
- [ ] **gate --repo vs позиционные** (живой тест Core 0.4.8):
  `gate --repo <path>`, но `control check <path>`/`model validate <path>`
  позиционные. Фикс-кандидат: принять позиционный `<repo>` у gate как
  синоним (или задокументировать асимметрию в --help). Критерий: оба
  синтаксиса gate работают.

  0.4.8): warn «нет целей p99 — проверить полноту модели».
