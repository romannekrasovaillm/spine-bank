# Паттерны и модель зрелости

## Паттерны интеграции LLM
| Паттерн | Когда | Риски |
|---|---|---|
| Прямой вызов модели через шлюз | генерация, классификация, извлечение | без контекста компании |
| RAG | ответы по внутренним документам | качество поиска, права доступа к документам |
| Агент с инструментами | многошаговые задачи с действиями | безопасность, стоимость, надёжность |
| Workflow (детерминированный граф + LLM-шаги) | повторяемые процессы с требованиями к контролю | меньше гибкости, но предсказуемо — часто лучше «свободного» агента |
| Мультиагентность (оркестратор + суб-агенты) | параллельные исследовательские задачи, изоляция контекста | стоимость ×N, сложность отладки |
| Batch/офлайн | разметка, суммаризация архивов | дешевле (batch API, загрузка своего парка ночью) |
| Человек в контуре | действия с последствиями | задержки; UX подтверждений |

Правило: выбирай самый простой паттерн, решающий задачу (вызов → workflow →
агент), и усложняй только по результатам эвалов.

## Модель зрелости AI-платформы
| Уровень | Признаки | Следующий шаг |
|---|---|---|
| 1. Эксперименты | разрозненные ключи API, нет учёта, пилоты | единый шлюз, политика данных |
| 2. Базовая платформа | шлюз, учёт затрат, 1–2 модели, базовый RAG | наблюдаемость, эвалы, каталог моделей |
| 3. Управляемая | эвалы в CI, трассы, guardrails, реестр инструментов/MCP, self-hosted для чувствительных данных | агентный рантайм, мульти-арендность, FinOps |
| 4. Агентная | агенты в процессах с правами и аудитом, онлайн-эвалы, маршрутизация по стоимости/качеству | автоматизация оптимизации, переиспользуемые компоненты |
| 5. Оптимизированная | непрерывная оптимизация стоимости/качества, собственные дообученные модели где оправдано | — |

## Дорожная карта (шаблон)
- 0–3 мес: шлюз + политика данных + учёт; 2–3 пилотных сценария с эвалами.
- 3–6 мес: наблюдаемость, RAG-платформа с правами, реестр инструментов/MCP, guardrails.
- 6–12 мес: self-hosted инференс для чувствительных/массовых нагрузок (по TCO),
  агентный рантайм, эвалы в CI, FinOps по командам.
