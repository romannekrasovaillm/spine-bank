# Чек-лист нефункциональных требований AI-решений

## Производительность
- [ ] SLA по TTFT и скорости генерации для интерактивных сценариев; по времени задачи — для агентов
- [ ] Пиковая нагрузка, рост, сезонность; пропускная способность batch-контура
- [ ] Лимиты контекста и длины ответа; поведение при превышении

## Надёжность
- [ ] Доступность (например, 99.5–99.9%) и как обеспечена: N+1 реплики, несколько зон, fallback на другую модель/провайдера
- [ ] Поведение при деградации: очередь, упрощённая модель, понятная ошибка
- [ ] Таймауты и ретраи с идемпотентностью для действий агентов
- [ ] Восстановление долгих агентных задач (чекпойнты состояния)

## Безопасность и соответствие
- [ ] Классификация данных и что можно отправлять каким моделям (внешний API / внутренняя модель)
- [ ] Размещение и обработка персональных данных по требованиям законодательства (например, 152-ФЗ в РФ) и отраслевых регуляторов — согласовано с ИБ и юристами
- [ ] Аутентификация пользователей и агентов, минимальные привилегии инструментов
- [ ] Защита от prompt injection и утечек (набор безопасности агентов)
- [ ] Аудит: кто, когда, какой моделью, с какими данными, какие действия выполнены
- [ ] Хранение и маскирование логов/трасс

## Качество
- [ ] Метрики качества и набор эвалов до запуска; порог приёмки
- [ ] Онлайн-мониторинг качества, обратная связь пользователей
- [ ] Процесс смены модели/промпта (регрессионные эвалы, откат)
- [ ] Ограничение галлюцинаций: опора на источники, цитирование, отказ при неуверенности

## Эксплуатация и стоимость
- [ ] Наблюдаемость (трассы, метрики, алерты)
- [ ] Учёт затрат по командам/продуктам, бюджеты и квоты
- [ ] Управление версиями моделей и зависимостей; план обновлений
- [ ] Изоляция арендаторов (данные, индексы, квоты)

## Этика и прозрачность
- [ ] Пользователь знает, что взаимодействует с ИИ; маркировка сгенерированного контента там, где требуется
- [ ] Человек в контуре для решений с существенными последствиями
