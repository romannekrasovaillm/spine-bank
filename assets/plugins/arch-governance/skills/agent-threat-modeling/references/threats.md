# Угрозы агентных систем (OWASP LLM Top 10 + Agentic)

## Инъекции и управление поведением
- **Prompt injection (прямая)**: пользователь обходит инструкции/ограничения.
- **Indirect prompt injection**: вредоносные инструкции приходят в данных,
  которые агент читает (веб-страница, письмо, PDF, тикет, README, результат
  MCP, комментарий в коде). Главная угроза для агентов с инструментами.
- **Jailbreak**: обход политик безопасности модели.

## Избыточные полномочия и действия
- **Excessive agency**: у агента больше прав/инструментов, чем нужно; инъекция
  превращает их в действия (удаление, перевод средств, отправка данных).
- **Confused deputy**: агент с легитимными правами выполняет действие в
  интересах злоумышленника (например, по инструкции из прочитанного документа).
- **Небезопасный вывод**: результат модели исполняется как код/SQL/команда без проверки.

## Данные
- **Утечка чувствительных данных**: через ответ, параметры инструмента,
  сетевой вызов, ссылку с данными в query-string, сообщение об ошибке.
- **Отравление памяти**: злоумышленник записывает в долговременную память
  агента инструкции/факты, влияющие на будущие сессии.
- **Утечка системного промпта/инструментов**.

## Цепочка поставок и экосистема
- **Tool poisoning**: вредоносное описание MCP-инструмента (скрытые инструкции
  в описании, видимые модели) заставляет агента действовать во вред.
- **Rug pull**: MCP-сервер/пакет меняет поведение после установки (незакреплённая версия).
- **Supply chain**: скомпрометированный пакет/скилл/суб-агент.
- **Отравление данных RAG**: вредоносный контент в индексируемых источниках.

## Ресурсы и надёжность
- **Отказ/перерасход (DoS, unbounded consumption)**: зацикливание, лавинообразные
  вызовы инструментов, исчерпание бюджета токенов.
- **Каскадные сбои** в мультиагентных системах.

## Мультиагентные специфические
- Доверие к выводу другого агента как к доверенному, распространение инъекции
  между агентами, обход контроля через делегирование суб-агенту с большими правами.
