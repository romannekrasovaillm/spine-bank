# Первый зелёный: каркас → бандл → PASS

Критический маршрут требует 13 артефактов. Порядок прохождения — не
алфавитный: спайн → правила → модель → бандл. Проводник называет СЛЕДУЮЩУЮ
красную находку:

```bash
arch-be bootstrap "Зарплатные и социальные выплаты" --dir кейсы/salary --domain payments
arch-be bootstrap --status --dir кейсы/salary     # спайн ✓ · правила ✓ · модель ✗ (2 находки) · бандл 7/13
```

Каркас намеренно КРАСНЫЙ: его заглушки ловит семантика бандла (Н1). Зелёный
каркас означал бы, что «ничего не написано» проходит как «выпуск разрешён».

## Протокол

1. `arch-be bootstrap <имя> --dir <каталог>` — каркас и первый шаг. Каталог
   становится git-репозиторием с одним коммитом (дельта-протокол работает
   от базы); внутри чужого репозитория коммит делает вызывающий.
2. После каждой правки — `arch-be bootstrap --status --dir <каталог>`:
   находка, подсказка, следующая стадия.
3. Бандл заполняется по одному артефакту. Ключи и то, что в них ждут:
   `problem`, `spec_or_delta`, `risk_level`, `acceptance`, `rollback`,
   `adr_or_pattern`, `spine`, `decision_a3`, `walking_skeleton`,
   `adversarial_review`, `rollback_rehearsal`, `validation`, `fitness_report`.
4. Переупаковка ПОСЛЕ правки: `arch-be evidence pack . --route critical`.
   Правка артефакта без переупаковки — `изменён после упаковки`, а не
   «незаметная мелочь».

## Что механика проверит, а что нет

- `evidence_stub` — артефакт короче `[evidence] min_bytes` (по умолчанию 200)
  или содержит `TODO`/`<незаполненное место>`. Проверяются все 13.
- `review_not_ready` — ревью поставило `VERDICT: NOT-READY`; выпуск не
  подтверждён ревьюером. Нужна строка `VERDICT: READY`.
- `a3_not_signed` — пустое поле записи A3 (`choice`, `rationale`, `rejected`,
  `expiry`, `decided_by`). Решение A3 подписывает ЧЕЛОВЕК: агент оставляет
  `decided_by` пустым и показывает, что гейт это ловит.
- `rollback_rehearsal` — репетиция отката на гейте A4 обязана быть PASS и
  относиться к тому же baseline, что план отката.
- `decision_quality` (если включена) — балл рубрики-судьи не ниже порога;
  судья обязан отличаться от автора документа.

Чего зелёный НЕ означает, печатает паспорт вердикта:
`arch-be gate --explain` (или MCP `verdict_explain`).

## Антипаттерны

- Написать артефакты «под линтер»: механика ловит заглушки, но не смысл —
  за смысл отвечает состязательное ревью, и оно не должно быть формальным.
- Подписать A3 от имени агента: `decided_by` — поле человека.
- Оставить правку артефакта без переупаковки бандла.
