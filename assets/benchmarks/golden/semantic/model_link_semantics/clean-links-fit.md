ADR-001 · Источник истины о кошельке — платформа ЦР, в банке только проекция
Тип: adr (архитектурное решение)   Статус: Accepted
Дата: 2026-09-19
Файл: model/ADR-001-istochnik-istiny-platforma-cr.md
  affects → CMP-002, CMP-004, CMP-006
  implements → AD-001

Платформа ЦР — источник истины; в банке проекция с меткой свежести и признаком
derived. Полный текст и альтернативы — docs/adr/ADR-001-istochnik-istiny-platforma-cr.md.

Решение меняет свойство трёх компонентов: оркестратор (CMP-002) определяет исход
операции только по ответу платформы или по сверке, а не по локальной проекции;
реестр кошельков (CMP-004) хранит остаток как производную величину с меткой
свежести и признаком derived; сверка (CMP-006) разрешает операции в UNKNOWN по
выписке платформы и не правит расхождения автоматически. Все три опираются на
инвариант AD-001: несвежая проекция не используется для исполнения.
