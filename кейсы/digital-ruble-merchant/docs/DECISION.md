# Запись решения A3

- **choice**: единый адаптер платформы и обязательная сверка
- **rationale**: Раздел описывает решение и его границы: какие варианты рассмотрены, почему выбран этот, чем платим за выбор и что произойдёт при отказе. решение снимает основной риск — потерю следа операции при неопределённом исходе ответа платформы.
- **rejected**: распределённый разбор по каждому каналу — отклонён как непроверяемый на текущем профиле нагрузки.
- **expiry**: 2099-12-31
- **decided_by**: архитектор контура приёма
