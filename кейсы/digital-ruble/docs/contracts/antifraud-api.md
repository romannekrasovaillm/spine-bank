# Контракт: антифрод-скоринг переводов цифрового рубля

Стык с антифрод-платформой банка. Вызывается до отправки поручения на
платформу ЦР; результат влияет на исполнение.

## Запрос

| Поле | Смысл |
|---|---|
| идентификатор поручения | ключ идемпотентности проверки |
| клиент | внутренний идентификатор, без лишних персональных данных |
| вид операции | перевод C2C, оплата C2B, возврат |
| сумма и валюта | сумма операции |
| получатель | идентификатор в объёме, разрешённом политикой данных |
| признаки канала | устройство, канал, признак смены устройства |
| факт 2FA | подтверждено ли вторым фактором |

## Ответ

| Поле | Значения | Действие сервиса |
|---|---|---|
| решение | `pass` | поручение уходит на платформу |
| решение | `step_up` | требуется дополнительное подтверждение клиента |
| решение | `stop` | поручение не отправляется, клиент уведомляется, случай журналируется |
| причина | код сработавшего правила | пишется в журнал, клиенту не раскрывается в деталях |

## Правила

- Таймаут антифрода — не `pass`: при недоступности антифрод-платформы
  применяется консервативное правило (по сумме и виду операции), зафиксированное
  политикой, а не «пропустить и забыть».
- Решение `stop` не переопределяется сервисом; разблокировка — только
  человеком.
- Персональные данные передаются в минимальном объёме; полный набор реквизитов
  получателя сервису недоступен.
