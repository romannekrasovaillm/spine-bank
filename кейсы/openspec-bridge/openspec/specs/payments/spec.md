# payments — приём платежей

Живая спецификация capability `payments`. История изменений — в
`openspec/changes/archive/`; работа в процессе — в активных `openspec/changes/`.

### Requirement: Идемпотентный приём
Сервис SHALL принимать платёж по ключу идемпотентности не более одного раза.
Повторная доставка с тем же ключом MUST возвращать исходный ответ без второго эффекта.

#### Scenario: повторная доставка
- **WHEN** один и тот же запрос доставлен дважды
- **THEN** создан ровно один платёж, ответ равен первому

### Requirement: Точные деньги
Сервис SHALL хранить суммы в minor units (копейки, целые).
Сервис MUST NOT использовать типы с плавающей точкой для денежных сумм.

#### Scenario: запись суммы
- **WHEN** сумма платежа записывается
- **THEN** она хранится целым числом копеек
