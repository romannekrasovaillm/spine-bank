# Delta: payments (change add-limits)

## ADDED Requirements

### Requirement: Лимиты на приём
Сервис SHALL проверять сумму платежа против лимита операции до исполнения.
При превышении лимита сервис MUST отклонить платёж без побочного эффекта.

#### Scenario: превышение лимита
- **WHEN** сумма платежа больше лимита операции
- **THEN** платёж отклонён, исполнения не было
