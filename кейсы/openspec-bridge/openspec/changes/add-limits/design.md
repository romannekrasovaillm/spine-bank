# Design: add-limits

## Контекст

Контур приёма исполняет платёж сразу после дедупликации. Проверка лимита
должна стоять между дедупликацией и исполнением: отказ обязан оставить ноль
побочных эффектов.

## Решение 1: лимит — синхронная проверка до исполнения

Движок лимитов не ходит во внешние системы: лимит операции — конфигурация
контура. Проверка чистая (без состояния), поэтому безопасна при повторной
доставке.

## Constraints

- Проверка лимита не создаёт записей и не расходует бюджет при отказе.
- Новых внешних зависимостей нет.
