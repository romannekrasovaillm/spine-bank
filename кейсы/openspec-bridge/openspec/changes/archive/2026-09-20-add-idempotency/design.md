# Design: add-idempotency

## Контекст

Канал доставки не гарантирует exactly-once; дедупликация — обязанность приёмной
стороны.

## Решение 1: ключ идемпотентности на точке входа

Ключ приходит с запросом; повтор с тем же ключом возвращает первый ответ.
Дедупликация — в одной транзакции с эффектом.

## Constraints

- Хранилище видимых ключей — часть контура приёма, без внешних сервисов.
