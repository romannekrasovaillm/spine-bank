# Delta: payments (change add-idempotency)

## ADDED Requirements

### Requirement: Идемпотентный приём
Сервис SHALL принимать платёж по ключу идемпотентности не более одного раза.
Повторная доставка с тем же ключом MUST возвращать исходный ответ без второго эффекта.

#### Scenario: повторная доставка
- **WHEN** один и тот же запрос доставлен дважды
- **THEN** создан ровно один платёж, ответ равен первому
