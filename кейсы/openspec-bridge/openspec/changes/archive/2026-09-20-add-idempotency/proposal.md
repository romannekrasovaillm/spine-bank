# Change: add-idempotency (реализован)

## Why

Повторная доставка запроса от канала — штатное событие сети; без ключа
идемпотентности повтор создавал второй платёж.

## What Changes

- Точка входа принимает ключ идемпотентности и дедуплицирует по нему.
- `model/CMP-001-priyom-platezhey.md`: компонент приёма фиксирует дедупликацию.
- `src/intake/`: дедупликация по ключу в точке входа.
