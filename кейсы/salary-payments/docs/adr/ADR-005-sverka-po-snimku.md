# ADR-005. Отчёт сверки строится по неизменяемому снимку журнала

- **Статус**: Accepted
- **Дата**: 2026-09-19

## Context

Отчёт сверки нужен как доказательство: он предъявляется получателю,
работодателю и регулятору. Если отчёт строится по «текущему состоянию»
журнала, две сверки одного окна могут дать разные ответы — доказательство
перестаёт быть воспроизводимым.

## Decision

На момент закрытия окна снимается **неизменяемый снимок** журнала; отчёт
сверки строится по нему и по снимку окна платформы. Повторный прогон отчёта
на тех же снимках даёт тот же результат.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---|---|---|
| А. Отчёт по текущему журналу | не нужно хранилище снимков | два прогона дают разные результаты; доказательство не воспроизводимо |
| Б. Снимок журнала на закрытие окна — **выбран** | воспроизводимость, независимость от последующих правок | нужен объём хранения и правило ретенции |
| В. Отчёт только по данным платформы | одна сторона, меньше работы | журнал перестаёт быть источником доказательства при обращении |
| Г. Непрерывная сверка в реальном времени | расхождение видно раньше | потоковая сверка не даёт точки, к которой можно вернуться |

## Consequences

- Положительные: отчёт воспроизводим и предъявляем; расхождение фиксируется
  на момент окна, а не «примерно тогда».
- Отрицательные: хранение снимков — дополнительные расходы и правило удаления
  по истечении срока хранения.
- **Обратимость**: полная. Снимок лишь фиксирует момент; следующий отчёт
  строится заново, отказ от снимков не требует миграции данных.
