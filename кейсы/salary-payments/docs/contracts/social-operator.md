# Контракт: система оператора социальных выплат

Внешняя граница INT-003 (G2C). Отличается от зарплатного канала тем, что
реестр формируется по категориям получателей и допускает отзыв строки.

## Операции

| Операция | Назначение |
|---|---|
| `POST /registries` | передать реестр социальных выплат |
| `GET /registries/{id}/status` | статусы строк: `paid`, `rejected`, `under_review` |
| `POST /registries/{id}/revoke` | отозвать строку до начала окна |

## Правила

- Отзыв строки до начала окна — не выплата и не отказ: строка исключается из
  реестра компенсирующей записью журнала (AD-2).
- Статус `under_review` соответствует состоянию разбора у нас; повторная
  отправка такой строки запрещена (AD-3).
- Расхождение числа строк на нашей стороне и на стороне оператора — предмет
  сверки; молчаливый пропуск строки недопустим (AD-7).
