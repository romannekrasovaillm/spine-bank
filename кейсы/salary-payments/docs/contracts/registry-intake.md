# Контракт: канал загрузки реестра выплат

Внешняя граница INT-002. Реестр приходит от работодателя (B2C) или от
оператора социальных выплат (G2C).

## Формат и приём

| Поле | Обязательно | Примечание |
|---|---|---|
| `registry_id` | да | идентификатор реестра у источника; половина ключа идемпотентности |
| `source_kind` | да | `salary` (B2C) или `social` (G2C) — различает отчётность |
| `rows[]` | да | строки: `row_no`, `amount_minor`, `destination_ref` |
| `checksum` | да | контрольная сумма файла |

## Правила приёма

- Реестр принимается **целиком либо не принимается вовсе**: частично принятый
  реестр источник не сможет ни повторить, ни отозвать.
- Повторная загрузка того же `registry_id` не создаёт вторую выплату: строки с
  уже применённым ключом игнорируются, ответ содержит их число.
- Персональные данные получателя в канал не входят: реквизиты приходят
  ссылкой (`destination_ref`), разрешаемой внутри контура (AD-4).
