# Зарплатные и социальные выплаты

Каркас кейса, созданный `arch-be bootstrap`. Он КРАСНЫЙ: артефакты бандла — заглушки.

Дорожка до зелёного:

```bash
arch-be bootstrap --status --dir .   # что ещё не так и что делать
arch-be gate --repo . --explain      # паспорт вердикта: чего зелёный не означает
```

Домен: выплат. Порядок шагов — спайн → правила → модель → бандл.
