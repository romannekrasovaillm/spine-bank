# ADR-012. Арбитраж спорного исполнения — решение человека

- Date: 2026-09-19
- Status: Accepted

## Context

Расхождение сторон по исполнению условия — не техническая ошибка, а конфликт
интересов. Автоматика в такой ситуации либо «дорешает» по формальному признаку
(таймаут, приоритет стороны, доля голосов), либо зависает. Первое создаёт
решение, которое нечем обосновать; второе блокирует средства навсегда.

## Decision

При расхождении сторон платёж переводится в состояние спора, и **любое**
движение средств по нему приостанавливается. Выход из спора — решение
человека с обязательной фиксацией: основание решения, ссылка на версию
условия, запись в журнале. Автоматическое разрешение спора запрещено; система
обязана лишь собрать полный материал (версия условия, обе стороны, история
состояний операции, результат сверки) и не дать принять решение, не опираясь
на него.

## Alternatives Considered

| Вариант | Почему отклонён |
|---|---|
| Автоматическое разрешение по таймауту в пользу стороны | решение без основания, репутационно неприемлемо |
| Автоматическое разрешение по признаку «кто первый подтвердил» | подменяет содержание договорённости процедурой |
| Постоянная блокировка до внешнего суда | средства зависают, банк становится участником спора |

## Consequences

### Positive

- Каждое спорное решение объяснимо и имеет след.
- Банк не принимает содержательное решение за стороны.

### Negative

- Возникает операционная функция разбора споров с её SLA
  (`OWNER-001`, `CMP-013`), которой нет в обычном переводе.
- Спор не имеет автоматического срока закрытия: срок задаётся регламентом, а
  не таймером системы.
