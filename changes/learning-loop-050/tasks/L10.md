# Задача L10 (spine-bank 0.5.0, волна 3): межрепозиторная и организационная память уроков

Прочитай ПЕРВЫМ: этот файл. Далее: TASK-Spine-0.5.0-learning-loop.md (§1, §5 L10, §7 риск 6), docs/adr/ADR-091 (твоё решение), docs/adr/ADR-085 (реестр), src/lessons/ (API), AGENTS.md, docs/RUST_CONVENTIONS.md.

Объём — СТРОГО L10:
1. `arch-be lessons export --scope repo --min-status confirmed` → lessons-bundle/v1: JSON с evidence-хэшами, версией arch-be и подписью SHA-256 (паттерн receipt как у archify). (В L1 export/import уже есть в базовой форме — доведи до lessons-bundle/v1: поле v, хэши evidence, подпись.)
2. `import` в уровень user/org — с ПОНИЖЕНИЕМ статуса до candidate (чужой урок подтверждается своим гейтом). Урок с несовпавшим хэшем отклоняется (тест).
3. Org-реестр — каталог/git-репозиторий, путь в [lessons] org_dir; доступ через MCP (Core).
4. Уроки уровней user/org не пишутся в файлы репозитория без флага --share (анти-утечка).

Тесты: импорт понижает статус; подпись проверяется; урок с битым хэшем отклоняется; export → import в другой репозиторий даёт candidate.

ПРОЦЕСС (жёстко): никаких фоновых команд — всё foreground по одной; export CARGO_TARGET_DIR=$PWD/target-local; ВЕРИФИКАЦИЯ ТОЛЬКО TARGETED: cargo fmt --check; cargo clippy --all-targets -- -D warnings; cargo test --lib lessons; cargo test --test lessons_ledger; cargo test --no-default-features --features core --lib lessons. ПОЛНЫЙ cargo test и control check ЗАПРЕЩЕНЫ (оркестратор). Коммит ОДИН: `feat(L10): lessons-bundle/v1 с SHA-256, понижение статуса при импорте, org-реестр (ADR-091)`. Не трогай CHANGELOG.md. Финал — блок ```json {"status": "complete|partial|blocked", ...}``` обязателен.
