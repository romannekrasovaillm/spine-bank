# Задача L3 (spine-bank 0.5.0, волна 1): инъекция уроков в контекст и защита от компактификации

ОБЯЗАТЕЛЬНО прочитай: TASK-Spine-0.5.0-learning-loop.md (§1, §5 пункт L3, §7 риски 1–3), docs/adr/ADR-087 (твоё решение), docs/adr/ADR-085 (реестр уроков, уже реализован в L1 — используй его API), AGENTS.md, docs/RUST_CONVENTIONS.md.

Объём — СТРОГО L3:
1. [Harness] Закреплённый блок `## Уроки контура (выучено, проверено гейтом)` при старте сессии и перед каждым harness_run: top-K уроков по scope к cwd и путям задачи; K и лимит токенов — из [lessons] конфига (поля уже объявлены в L1).
2. L1-маскирование и L3-саммари блок НЕ трогают: после компактификации блок ПЕРЕСОБИРАЕТСЯ из реестра, а не пересказывается (B5).
3. Миграция failure_lessons.md в реестр (B1, B2); failure_memory получает сигнатуры источников gate и fitness.
4. [Core] Новые события хуков: `arch-be hook session-start` (уроки области репо) и `arch-be hook user-prompt-submit` (уроки по путям из текста; BM25 из src/kb.rs). connect ставит их для Claude Code и Kimi Code (src/connect/hooks.rs), fail-soft как у существующих.
5. Гигиена: блок оборачивается маркером данных, проходит src/injection.rs; урок с признаками prompt-injection → quarantine, в блок не попадает.
6. Субагенты и ralph (B8): в свежий контекст передаётся ТОЛЬКО блок уроков.

Тесты (сначала падающие):
- блок присутствует после compact_now (пути L1 и L3);
- лимит токенов блока соблюдён;
- урок «ignore previous instructions» → quarantine;
- hook session-start без реестра → пустой вывод, exit 0 (fail-soft);
- синтетический B5: 50 ходов шума после урока → compact_now → блок цел.

БЕЗ новых зависимостей. Всё за [lessons] enabled (дефолт false). Не трогай: src/harness.rs accept-логику (это L2, отдельный коммит), src/lessons/ (L1), CHANGELOG.md.
