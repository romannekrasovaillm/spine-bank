# Задача L6 (spine-bank 0.5.0, волна 2): обобщение и композиция уроков

Прочитай ПЕРВЫМ: этот файл. Далее: TASK-Spine-0.5.0-learning-loop.md (§1, §5 L6, §3 E3/E4), docs/adr/ADR-088 (твоё решение), docs/adr/ADR-085 (реестр), src/lessons/ (API, включая match.rs из L4), AGENTS.md, docs/RUST_CONVENTIONS.md.

Объём — СТРОГО L6 (критерии E3, E4):
1. **Расширение области (детерминированно):** урок с одной сигнатурой, подтверждённый в ≥ 2 разных модулях одного пакета, поднимается до package; в ≥ 2 пакетах — до repo. Контрпример (miss в новой области) откатывает область назад. Счётчики в evidence, переходы только по ним (AD-2).
2. **Композиция:** уроки, ≥ 2 раз проваливавшиеся в одной задаче или по одному subject_kind («новый публичный символ», «новая миграция», «новый эндпоинт»), сворачиваются в составной чек-лист LSN-C-* со ссылками на исходные. Статус составного — не выше минимального из исходных; урок с misses > 0 в композицию не входит.
3. **Классификатор subject_kind** — детерминированный, по диффу исполнителя (новый файл в пакете / новый публичный символ / новый маршрут / новый SQL); переиспользуй recover/arch_diff.
4. **LLM — только формулировка:** statement составного урока может быть [inferred]; применимость решает счётчик.

Тесты: табличные сценарии расширения и отката области; детерминизм композиции; урок с misses > 0 не входит в композицию.
