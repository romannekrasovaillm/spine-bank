# Дельта: perimeter-trust
- Route: Critical (security_boundary + trust_zone; ADR-083, решение человека A3 — «всё сразу»)
- Created: 2026-10-12

## Проблема

SEAF-испытание v3 (Spine 0.4.6): измеримый отрицательный результат против
агента без Spine — инструменты не вызывались (report нет в MCP; recover
«бесполезен для v3»; Harness без init теряет скиллы молча) + четыре дефекта
периметра доверия: fs-инструменты читают/пишут вне рабочего каталога
(tool.rs:130), нечитаемый явный --config молча даёт дефолты с DeepSeek
(config.rs:2025), веб включён по умолчанию (config.rs:2369), kind=cli без
tool-calls. Решение — ADR-083 (Accepted, судья 4.40/5, A3 владельца).

## ADDED

- When fs-инструмент (read_file/write_file/edit_file/glob/grep) получает
  путь, разрешающийся вне рабочего каталога (canonicalize обеих сторон),
  the система shall отказать (is_error) с текстом обоих путей и записать
  событие в журнал политики/аудита сессии.
- When в конфиге задан `[tools] fs_allow = ["/abs/path"]`, the система
  shall расширить зону на перечисленные корни (легитимные исключения;
  init прописывает ~/.arch-harness по умолчанию).
- When задан явный `--config <path>`, который не читается или не парсится,
  the система shall завершить запуск с ошибкой (exit ≠ 0), БЕЗ fallback
  на дефолты; When путь не задан — прежняя кандидатная цепочка → default.
- When агентный цикл стартует без явно настроенного провайдера, the
  система shall отказать с перечнем вариантов (усиление UX-6 0.4.9).
- When запрошен профиль `reverse` (`arch-be run --profile reverse`),
  the система shall: выключить веб-инструменты, включить read-only зону
  cwd (запись только в каталог вывода), обеспечить встроенный минимальный
  набор скиллов восстановления без init (warn в журнале, если библиотека
  пользователя пуста).
- When MCP-клиент вызывает инструмент `report`, the система shall вызвать
  строитель src/report/ (AD-11) с параметрами path/format/rev — read-only,
  BRIDGE_READ_ONLY.
- When провайдер kind=cli используется в агентном цикле, the система
  shall поддерживать tool-calls (переиспользование ACP-протокола);
  до реализации — честный отказ при старте цикла (не поломка на полпути).
- docs/threat-model.md: дополнение строк fs-периметра (закрытие
  существующей T-строки обхода, не новая угроза).

## MODIFIED

- `src/tool.rs` ToolContext::resolve → зона + canonicalize (точечная
  правка, все fs-инструменты через неё).
- `src/config.rs`: load(cli_path) fail-closed; дефолт [web].enabled
  пересматривается только в профиле reverse (глобальный дефолт —
  решение в реализации по миграционной честности; CHANGELOG «покраснеть»).
- MCP-справка/счётчики (тест реестра), AD-11 (мост = тонкая обёртка).

## REMOVED

- Ничего; fs_sandbox = false в конфиге — аварийный откат (документирован,
  не по умолчанию).

## План отката

Costly (см. ADR-083 Reversibility): откат поведения — конфиг-флаги
fs_sandbox=false / кандидатная цепочка; после приёмки в периметре банка
откат — событие безопасности с фиксацией. Технически — git revert дельты.

## Критерии приёмки

- [ ] read_file('/etc/passwd') из агента с cwd=/tmp/x → отказ + запись в
      журнал; write_file вне cwd → отказ; с fs_allow=~/.arch-harness →
      запись туда работает (тесты на все три).
- [ ] --config на битый файл → exit ≠ 0 с путём и причиной (не дефолты).
- [ ] Профиль reverse: веб-инструментов нет в списке, запись в cwd
      блокируется, каталог вывода доступен, скиллы без init с warn.
- [ ] MCP tools/list содержит report; вызов отдаёт тот же JSON, что CLI
      (детерминизм, тест паритета).
- [ ] kind=cli: либо tool-calls работает (интеграционный тест), либо
      честный отказ на старте цикла.
- [ ] cargo test зелёный (включая ВСЕ существующие тесты, где пути были
      вне cwd — мигрировать на fs_allow в фикстурах, НЕ ослаблять песочницу);
      fmt/clippy/MSRV 1.85; CHANGELOG «Что может покраснеть» (ломка
      легитимных записей вне cwd — fs_allow; fail-closed конфиг).
