# ADR-041. Исключение left-pad из тех-радара (Hold)

- Date: 2026-01-15
- Status: Accepted
- Reversibility: обратимо — снятие override в `CONSTRAINTS.yaml` возвращает
  правило C-CORP-001 в полную силу

## Context

Корпоративное правило C-CORP-001 (`tech_radar_hold`, `deny_dependency`)
держит библиотеку `left-pad` в кольце Hold. Продуктовый репозиторий
использует `left-pad` в `Cargo.toml`. Это осознанное, датированное
исключение: зависимость нужна для совместимости до планового вывода.

## Decision

Узаконить ослабление C-CORP-001 **через override с ограниченным сроком**:
`rule: C-CORP-001`, `adr: ADR-041`, `until: "2027-01"`. Исключение видно в
выводе `control check` и в `control report`, протухает по сроку и не
превращается в молчаливое отключение.

## Alternatives Considered

| Вариант | Плюсы | Минусы |
|---------|-------|--------|
| Вывести left-pad немедленно | Правило действует без исключений | Блокирует поставку; нет ADR-обоснования срока |
| Отключить C-CORP-001 навсегда | Просто | Скрытое исключение, правило перестаёт защищать |

## Consequences

### Positive

- Поставка не блокируется, исключение датировано и обосновано.
- Тех-радар сохраняет силу для остальных репозиториев и зависимостей.

### Negative

- `left-pad` остаётся в репозитории до срока; риск тех-долга переносится.
- По истечении `until` правило снова действует — нужен явный пересмотр.
